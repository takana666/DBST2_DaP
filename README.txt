ダビスタ2 配合設計・全体最適化 v26

ZIPをすべて展開し、同じフォルダにあるindex.htmlをブラウザで開いてください。
使用データ：13-dabista2-data_20261003.js（今回指定されたソースをそのまま同梱）。

表示
・馬名は1～5代目の順に22、20、18、16、14px。5代目は従来サイズです。
・起動時は自動フィット。画面枠の縦横に収まる倍率へ調整します。
・＋／−や100%を押すと手動倍率になります。「自動フィット」で戻せます。
・自動フィットで文字が小さすぎる場合は＋で拡大し、スクロールできます。

編集
・↶は元に戻す、↷はやり直す。直近100状態を保持します。
・配置、血統表全消去、指定セル消去、世代送り、配合文の反映、最適化候補の反映、保存血統の配置が対象です。
・削除後も最適化の探索結果は残ります。
・判定は通常自動更新されます。「判定を更新」は手動で血統継承・理論・ニトロ・クロス・候補を再計算します。

血統の保存・呼出
1. 父と母を配置して血統を作ります。
2. 「血統を保存・呼出」を開き、名前と牡馬／牝馬／設定なしを選んで保存します。
3. 呼出先のセルを選び、もう一度「血統を保存・呼出」を開きます。
4. 「選択セルに配置」で、保存した父×母の産駒として配置します。
・牡馬は父側セル、牝馬は母側セル、設定なしは両方で呼び出せます。
・配置後は血統表の5代目までを表示します。保存血統自体に新しい因子は付与しません。
・呼出先は4代目までのセルです。5代目には父母を表示する余地がありません。
・保存一覧は選択セルで呼び出せる性別だけを表示します。
・上部または下部の「キャンセル」、画面外側のクリック・タップ、Escキーで閉じられます。
・ブラウザ内に保存します。別ブラウザ、別フォルダ、別PCへ移すときやバックアップには「保存データを書き出す」を使い、移行先でJSONを読み込んでください。

スクショ
・画面スクショ／血統表スクショは血統表全消去の左です。
・コピーが許可されないブラウザでは画像のプレビューからコピーまたはPNG保存できます。

検証
・新しいJSの完全一致、保存・呼出と性別条件、5代目への切詰め、元に戻す／やり直す、自動フィット計算、スクショ操作の保持、既存探索ロジックをテスト済み。
・実ブラウザの描画と実際のクリップボード操作は未検証です。
